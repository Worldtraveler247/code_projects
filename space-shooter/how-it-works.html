Galactic Guardian — How It's Built

Neon space shooter with enemy waves, particle effects, and mobile joystick controls.

Overview

Galactic Guardian is a horizontal space shooter built entirely with vanilla JavaScript and the HTML5 Canvas API. The player controls a spacecraft that fires projectiles at advancing enemy waves. As enemies die they drop power-ups that alter fire behavior. A boss enemy spawns at score milestones. On mobile, a virtual joystick and fire button replace keyboard controls. Everything — entities, projectiles, particles, stars, UI — is drawn by a single requestAnimationFrame loop.

Tech Stack

HTML CSS JavaScript Canvas API
  • HTML — a single <canvas> element plus mobile control overlays
  • CSS — fullscreen layout, mobile joystick/button positioning
  • JavaScript — all game logic: class-based entities, game loop, spawn schedules, input handling
  • Canvas API — every visual element is drawn with 2D context calls; no DOM sprites

How Each Part Works

game.js — entity classes

The game uses a class-based entity model. Each entity type (Player, Enemy, Boss, Projectile, PowerUp, Particle, Star) is a class with update(deltaTime) and draw() methods. The main loop calls update and draw on all active entities each frame. 

class Player {
    constructor() {
        this.x = 50;
        this.y = CANVAS_HEIGHT / 2 - 20;
        this.width = 60;
        this.height = 40;
        this.speed = 6;
        this.health = 100;
        this.shotDelay = 180;  // ms between shots
        this.powerUpType = null;
        this.powerUpTimer = 0;
    }

    update(deltaTime) {
        // Arrow keys OR joystick vector both move the player
        if (KEYS['ArrowUp'] || KEYS['KeyW']) this.y -= this.speed;
        if (KEYS['ArrowDown'] || KEYS['KeyS']) this.y += this.speed;
        this.x += joystickVector.x * this.speed;
        this.y += joystickVector.y * this.speed;

        // Clamp to canvas bounds
        this.x = Math.max(0, Math.min(CANVAS_WIDTH - this.width, this.x));
        this.y = Math.max(0, Math.min(CANVAS_HEIGHT - this.height, this.y));

        // Auto-fire on Space or fire button
        if (KEYS['Space'] && Date.now() - this.lastShot > this.shotDelay) {
            this.shoot();
            this.lastShot = Date.now();
        }
    }
}

game.js — requestAnimationFrame loop

The game loop receives a high-resolution timestamp from the browser. It computes deltaTime (time since last frame) and passes it to every entity's update method so physics are frame-rate independent. After all updates, it draws everything in z-order (stars first, entities last, UI on top). 

function gameLoop(timestamp) {
    const deltaTime = timestamp - lastTime;  // ms since last frame
    lastTime = timestamp;

    ctx.clearRect(0, 0, CANVAS_WIDTH, CANVAS_HEIGHT);

    if (gameState === 'PLAYING') {
        // Update all entities — each manages its own position/lifetime
        stars.forEach(s => s.update());
        particles = particles.filter(p => { p.update(); return p.life > 0; });
        if (player) player.update(deltaTime);
        enemies.forEach(e => e.update(deltaTime));
        projectiles.forEach(p => p.update());
        powerUps.forEach(p => p.update());

        checkCollisions();  // O(n×m) sweep — workable at game entity counts
        spawnEnemies(deltaTime);
    }

    // Draw everything (back to front)
    stars.forEach(s => s.draw());
    particles.forEach(p => p.draw());
    powerUps.forEach(p => p.draw());
    projectiles.forEach(p => p.draw());
    enemies.forEach(e => e.draw());
    if (player) player.draw();
    drawHUD();

    requestAnimationFrame(gameLoop);
}

game.js — mobile joystick

On touch devices, a virtual joystick div appears. Touch events track the finger's position relative to the joystick center, clamp the displacement to a maximum radius, then compute a normalized joystickVector {x, y} that the player's update() reads instead of keyboard state. This vector is reset to {0, 0} on touchend. 

function updateJoystick(touch) {
    const centerX = joystickBaseRect.left + joystickBaseRect.width / 2;
    const centerY = joystickBaseRect.top + joystickBaseRect.height / 2;
    let dx = touch.clientX - centerX;
    let dy = touch.clientY - centerY;

    const distance = Math.hypot(dx, dy);
    const maxDistance = joystickBaseRect.width / 2;

    // Clamp displacement to the joystick radius
    if (distance > maxDistance) {
        dx = (dx / distance) * maxDistance;
        dy = (dy / distance) * maxDistance;
    }

    // Normalize to -1..1 so the player moves at full speed at the joystick edge
    joystickVector.x = dx / maxDistance;
    joystickVector.y = dy / maxDistance;

    // Move the knob visually
    joystickKnob.style.left = `calc(50% + ${dx}px)`;
    joystickKnob.style.top  = `calc(50% + ${dy}px)`;
}

Replicate It Yourself

  1. Create a fullscreen canvas. Set canvas.width = 900; canvas.height = 600 and style it with display:block; margin:0 auto. Reference: MDN Canvas API.
  2. Model entities as classes. Each entity has x, y, width, height and update(dt) / draw() methods. Store them in arrays: enemies = [], projectiles = [], particles = [].
  3. Run the game loop with requestAnimationFrame. Compute deltaTime = timestamp - lastTime each frame and pass it to entity updates so movement is frame-rate independent. Reference: MDN requestAnimationFrame.
  4. Add touch controls. Detect 'ontouchstart' in window to show the joystick overlay. On touchstart, record the base position. On touchmove, compute the displacement vector and normalize it to -1..1. Pass this vector to the player's update() alongside keyboard state.
  5. Check collisions. For each projectile, loop over each enemy and test Math.hypot(proj.x - enemy.x, proj.y - enemy.y) < proj.r + enemy.r. Spawn particles at the impact point and remove both entities.
  6. Deploy to GitHub Pages. Push to main, go to repo Settings → Pages → Source: Deploy from branch → main / (root). Reference: GitHub Pages docs.
