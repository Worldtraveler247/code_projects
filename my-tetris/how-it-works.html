Tetris — How It's Built

Classic block-stacking in pure JavaScript and Canvas — no libraries, no framework.

Overview

This is a fully featured Tetris clone built with vanilla JavaScript and the HTML5 Canvas API. It includes all seven standard tetrominoes with neon gradient colors, ghost piece preview, particle burst effects when rows clear, a "Next piece" canvas, DAS/ARR keyboard repeat (the standard speed settings used in competitive Tetris), mobile touch buttons, and a game-over overlay. Everything runs in a single requestAnimationFrame loop with no external libraries.

Tech Stack

HTML CSS JavaScript Canvas API
  • HTML — two <canvas> elements: the main board and the "Next" preview pane
  • CSS — dark background, layout, mobile button positioning
  • JavaScript — all game logic: piece spawning, collision, rotation, row clearing, scoring, animation loop
  • Canvas API — every cell, ghost piece, particle, and popup is drawn with ctx.fillRect and ctx.arc; no DOM elements inside the game area

How Each Part Works

tetris.js — SHAPES and the board

Every tetromino is a 2D array of integers. The integer value is an index into the PAL (palette) array, so each piece carries its own color. The board (arena) is a 20×10 grid of zeroes; when a piece lands, its integers are copied into the arena via merge(). 

// Each shape is a 2D matrix. The non-zero values are color indices into PAL[].
const SHAPES = {
    T: [[0,1,0],[1,1,1],[0,0,0]],  // 1 = purple
    O: [[2,2],[2,2]],               // 2 = yellow
    L: [[0,3,0],[0,3,0],[0,3,3]],  // 3 = orange
    J: [[0,4,0],[0,4,0],[4,4,0]],  // 4 = blue
    I: [[0,5,0,0],[0,5,0,0],[0,5,0,0],[0,5,0,0]],  // 5 = cyan
    S: [[0,6,6],[6,6,0],[0,0,0]],  // 6 = green
    Z: [[7,7,0],[0,7,7],[0,0,0]],  // 7 = red
};

// The board: 20 rows × 10 columns, all zeroes at start
function makeArena() {
    return Array.from({ length: ROWS }, () => new Array(COLS).fill(0));
}

tetris.js — collision detection

collide() walks every cell of the active piece matrix. For each non-zero cell, it checks whether the destination cell on the board (arena) is already occupied or out of bounds. This one function is used for gravity drops, left/right movement, and rotation wall-kicks. 

function collide(ar, pl) {
    const { matrix: m, pos: o } = pl;
    for (let y = 0; y < m.length; y++) {
        for (let x = 0; x < m[y].length; x++) {
            if (!m[y][x]) continue;            // skip empty cells in the matrix
            const ny = y + o.y, nx = x + o.x; // translate to board coordinates
            if (ny >= ROWS || nx < 0 || nx >= COLS) return true; // out of bounds
            if (ar[ny]?.[nx]) return true;     // cell already occupied
        }
    }
    return false;
}

tetris.js — row clearing (sweep)

After a piece lands, sweep() scans every row from bottom to top. A full row (every cell non-zero) is collected. After a brief flash animation, those rows are spliced out of the arena array and new empty rows are prepended at the top. Points follow the Tetris scoring table: 100/300/500/800 multiplied by the current level. 

function sweep() {
    const found = [];
    for (let y = ROWS - 1; y >= 0; y--) {
        if (arena[y].every(v => v !== 0)) found.push(y); // full row
    }
    if (!found.length) return;

    flashRows = found;   // triggers white-flash animation in the draw loop
    setTimeout(() => {
        // Remove full rows (sorted descending so indices stay valid)
        found.slice().sort((a, b) => b - a).forEach(y => {
            arena.splice(y, 1);               // remove the full row
            arena.unshift(new Array(COLS).fill(0)); // add empty row at top
        });
        // Score: [0, 100, 300, 500, 800][rowsCleared] × level
        const pts = [0, 100, 300, 500, 800][found.length] * player.level;
        player.score += pts;
        player.lines += found.length;
        player.level  = Math.floor(player.lines / 10) + 1;
        flashRows = [];
        updateHUD();
    }, 280); // 280ms flash window
}

tetris.js — main game loop

The loop receives a time timestamp from requestAnimationFrame. It computes the delta since the last frame, advances the drop counter, and calls all draw functions. Gravity speed increases with level: dropInterval() returns max(60ms, 1000ms - level×90ms). 

function loop(time = 0) {
    const dt = time - lastTime;  // milliseconds since last frame
    lastTime = time;
    flashTimer += dt;

    if (!gameOver) {
        dropCounter += dt;
        // When enough time has passed (based on level), drop the piece one row
        if (flashRows.length === 0 && dropCounter > dropInterval()) playerDrop();

        // Update particles (they drift and fade each frame)
        particles = particles.filter(p => {
            p.x += p.vx; p.y += p.vy; p.vy += 0.14; p.life -= p.decay;
            return p.life > 0;
        });
    }

    drawBoard();
    drawArena();
    if (!gameOver) { drawPlayer(); drawParticles(); drawPopups(); }
    else drawGameOver();

    requestAnimationFrame(loop);  // schedule the next frame
}

Replicate It Yourself

  1. Set up two canvas elements. One for the board (260×520 for a 10×20 grid at 26px per cell), one small canvas for the next-piece preview. Get 2D contexts on both. Reference: MDN Canvas tutorial.
  2. Define SHAPES as nested arrays. Each piece is a 2D array of integers (0 = empty, 1-7 = color index). Store a color palette array PAL where index matches the integer so drawCell can look up colors without any conditionals.
  3. Write collide(arena, player). Walk every cell of the piece matrix. Translate each cell to board coordinates using pos.x and pos.y. Return true if any cell is out of bounds or lands on a non-zero board cell.
  4. Implement gravity with dropCounter. Each frame, add dt (milliseconds since last frame) to a counter. When the counter exceeds dropInterval(), call playerDrop() and reset the counter. This decouples speed from frame rate.
  5. Implement row clearing. After a piece merges, scan every row. If row.every(v => v !== 0), collect it. After a brief flash, splice those rows out and unshift empty rows at the top.
  6. Deploy to GitHub Pages. Push to main, go to repo Settings → Pages → Source: Deploy from branch → main / (root). Reference: GitHub Pages docs.
