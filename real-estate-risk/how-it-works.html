Real Estate Crash Indicator — How It's Built

14 FRED economic indicators, z-scored against 20-year history, averaged into a composite risk gauge.

Overview

The Real Estate Crash Indicator is a static dashboard that visualizes housing market stress using 14 indicators sourced from the Federal Reserve Economic Data (FRED) database — things like the Case-Shiller home price index, the Fed Funds rate, mortgage rates, delinquency rates, and the unemployment rate. Each indicator is z-scored against its 20-year history to make different units comparable, then averaged into a single 0–100 composite risk score that rotates a semicircle gauge needle. The pre-fetched data lives in a static JSON file; no API calls happen at page load.

How Each Part Works

data.json — pre-computed indicator data

Each indicator entry contains the raw historical values, the pre-computed z-score, a risk score (0–100 mapped from the z-score), and the percentile rank. Computing this offline (in a script or spreadsheet) and baking it into JSON means the page has zero load-time API dependencies and no rate limit exposure. 

// Each indicator in data.json looks like this:
{
  "id": "mortgage_rate",
  "name": "30-Year Fixed Mortgage Rate",
  "current": 6.82,
  "currentDate": "2025-04-01",
  "unit": "%",
  "zScore": 1.24,       // how many standard deviations above the 20-yr mean
  "riskScore": 62,      // mapped to 0-100 for the gauge
  "percentile": 78,     // where current value ranks in 20-yr history
  "description": "...",
  "history": [          // array of { date, value } for the sparkline
    { "date": "2005-01-01", "value": 5.77 },
    // ...
  ]
}

app.js — composite gauge drawing

The composite score (average of all indicator risk scores) controls the gauge needle. The gauge is a Canvas semicircle arc from π to 2π (left to right). The needle angle is computed as π + (score / 100) × π. The five colored background bands (green through red) give context for where the needle falls. 

function drawGauge(score) {
    const ctx = document.getElementById('gauge').getContext('2d');
    const cx = 175, cy = 170 * 0.92; // center of semicircle
    const radius = 130;

    // Five faint background color bands (green → yellow → orange → red)
    const bands = [
        { start: Math.PI,        end: Math.PI * 1.25, color: '#34d399' }, // low
        { start: Math.PI * 1.25, end: Math.PI * 1.45, color: '#a3e635' },
        { start: Math.PI * 1.45, end: Math.PI * 1.65, color: '#facc15' }, // moderate
        { start: Math.PI * 1.65, end: Math.PI * 1.80, color: '#fb923c' },
        { start: Math.PI * 1.80, end: Math.PI * 2,    color: '#ef4444' }, // critical
    ];
    bands.forEach(b => {
        ctx.beginPath();
        ctx.strokeStyle = b.color;
        ctx.globalAlpha = 0.18;
        ctx.lineWidth = 16;
        ctx.arc(cx, cy, radius, b.start, b.end);
        ctx.stroke();
    });

    // Active filled arc from 0 to score
    const target = Math.PI + (score / 100) * Math.PI;
    ctx.globalAlpha = 1;
    ctx.strokeStyle = levelColor(score); // color matches risk level
    ctx.arc(cx, cy, radius, Math.PI, target);
    ctx.stroke();

    // Needle line from center to arc edge
    const nx = cx + Math.cos(target) * (radius - 4);
    const ny = cy + Math.sin(target) * (radius - 4);
    ctx.strokeStyle = '#fff';
    ctx.lineWidth = 3;
    ctx.beginPath();
    ctx.moveTo(cx, cy);
    ctx.lineTo(nx, ny);
    ctx.stroke();
}

app.js — risk level mapping

Two simple helper functions convert a 0–100 score to a color and label. These are called throughout the app — on the gauge, on indicator cards, and in the detail modal — to keep all risk coloring consistent. 

function levelLabel(score) {
    if (score == null) return 'Unknown';
    if (score >= 80)   return 'Critical';
    if (score >= 65)   return 'High';
    if (score >= 45)   return 'Moderate';
    if (score >= 25)   return 'Low';
    return 'Minimal';
}

function levelColor(score) {
    if (score == null) return '#5a607a';
    if (score >= 80)   return '#ef4444';  // red
    if (score >= 65)   return '#fb923c';  // orange
    if (score >= 45)   return '#facc15';  // yellow
    if (score >= 25)   return '#a3e635';  // lime
    return '#34d399';                     // green
}

Replicate It Yourself

  1. Choose your indicators. Pick economic time series from FRED (Federal Reserve Economic Data). Good candidates for housing risk: Case-Shiller HPI, 30-yr mortgage rate, NAHB homebuilder sentiment, delinquency rate, foreclosure starts.
  2. Download CSVs and compute z-scores. For each indicator, download the CSV. Compute mean and stdDev over your lookback window. The z-score for each observation is (value - mean) / stdDev. A z-score of +2 means 2 standard deviations above normal — historically elevated.
  3. Map z-scores to a 0–100 risk scale. A simple linear mapping: clamp z-scores to the range [-2, +3], then scale to 0–100. Store the results in data.json alongside the history array for sparklines.
  4. Draw the semicircle gauge with Canvas. Use ctx.arc(cx, cy, radius, Math.PI, angle) where angle = Math.PI + (score/100) * Math.PI. Draw a line from center to arc edge as the needle. Reference: MDN ctx.arc.
  5. Render sparklines. For each indicator card, draw a small canvas with a polyline of historical values. Normalize the y-axis to the min/max of that indicator's history.
  6. Deploy to GitHub Pages. The data is static JSON so there are no server-side requirements. Push to main, go to repo Settings → Pages → Source: Deploy from branch → main / (root). Reference: GitHub Pages docs.
