Async 3D Chess — How It's Built

Fully playable chess with a 3D board, Firebase real-time sync, and orbit camera controls.

Overview

Async 3D Chess is a multiplayer chess game where two players can play asynchronously — they don't need to be online at the same time. The 3D board and Staunton-style pieces are rendered with Three.js entirely in the browser. chess.js handles move validation and game state so illegal moves are rejected client-side. Firebase Realtime Database stores the current board position as a FEN string; both browsers subscribe to the same database reference and update their 3D board whenever the other player moves. Players can orbit the camera, flip the board perspective, and enter their names persistently.

Tech Stack

HTML CSS JavaScript Three.js chess.js Firebase Realtime Database
  • HTML — the Three.js canvas container, UI side panel with player names and move log
  • CSS — dark panel layout, mobile-responsive side panel collapse
  • JavaScript — Three.js scene setup, raycasting for click-to-move, Firebase listener, game logic
  • Three.js — 3D renderer, camera, lighting, Staunton piece geometry (LatheGeometry), OrbitControls
  • chess.js — move validation, FEN parsing, check/checkmate detection; no rendering
  • Firebase Realtime Database — stores board FEN string; the onValue listener pushes updates to both browsers in real time

How Each Part Works

app.js — Three.js scene initialization

At startup, the script creates a Three.js scene, perspective camera, WebGL renderer, and three-point studio lighting. OrbitControls are attached to the renderer's DOM element so the user can orbit, zoom, and pan with mouse or touch. The renderer is appended to a <div id="canvas-container"> and resizes with the window. 

// Scene, camera, renderer — the three required Three.js objects
const scene = new THREE.Scene();
scene.background = new THREE.Color(0x08080c);
scene.fog = new THREE.FogExp2(0x08080c, 0.016); // subtle depth fog

const camera = new THREE.PerspectiveCamera(
    44,                                      // field of view (degrees)
    window.innerWidth / window.innerHeight,  // aspect ratio
    0.1,                                     // near clip plane
    100                                      // far clip plane
);
camera.position.set(0, 10, 11); // above and behind the board

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
document.getElementById('canvas-container').appendChild(renderer.domElement);

// OrbitControls: lets the user rotate/zoom the camera with mouse or touch
const controls = new THREE.OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;  // smooth inertia
controls.dampingFactor = 0.07;
controls.maxDistance = 22;
controls.maxPolarAngle = Math.PI / 2.05; // prevent going below the board

app.js — Firebase real-time sync

After anonymous sign-in, loadFromFirebase() attaches a firebase.database().ref('current_match').on('value', ...) listener. This listener fires immediately with the current state and again whenever any client writes to that reference. When a player makes a move, saveToFirebase() writes the new FEN string, which triggers the other player's listener. 

function loadFromFirebase() {
    if (typeof firebase === 'undefined' || firebase.apps.length === 0) return;

    firebase.auth().onAuthStateChanged(user => {
        if (!user) return;

        // .on('value', ...) fires immediately AND on every future change
        firebase.database().ref('current_match').on('value', snap => {
            const data = snap.val();
            if (!data) return;

            if (data.fen && data.fen !== game.fen()) {
                // Other player moved — load their position into chess.js
                game.load(data.fen);
                sync3DWithEngine();  // rebuild 3D piece meshes to match new FEN
            } else {
                updateStatus();      // same position — just refresh check/turn display
            }
        });
    });
}

function saveToFirebase() {
    if (!firebaseReady()) return;
    firebase.database().ref('current_match').set({
        fen:       game.fen(),       // chess.js board state as FEN string
        nameWhite: document.getElementById('name-white').value.trim(),
        nameBlack: document.getElementById('name-black').value.trim(),
        timestamp: Date.now(),
    });
}

app.js — click-to-move with raycasting

Three.js uses a Raycaster to translate a mouse click (2D screen coordinates) into a 3D ray that intersects the board tiles. Each tile mesh has a userData.square string like "e4". The first intersected tile with a square name is passed to handleSquareClick(), which delegates move validation to chess.js. 

const raycaster = new THREE.Raycaster();
const mouse     = new THREE.Vector2();

function pickSquare(clientX, clientY) {
    // Convert screen pixels to normalized device coordinates (-1 to +1)
    mouse.x =  (clientX / window.innerWidth)  * 2 - 1;
    mouse.y = -(clientY / window.innerHeight) * 2 + 1;

    raycaster.setFromCamera(mouse, camera);

    // Check which board tiles the ray intersects
    const hits = raycaster.intersectObjects(boardGroup.children, false);
    const hit  = hits.find(i => i.object.userData.square); // find first tile with a square name
    return hit ? hit.object.userData.square : null;        // returns "e4" or null
}

function handleSquareClick(square) {
    if (!selectedSquare) {
        const piece = game.get(square);
        if (piece && piece.color === game.turn()) {
            selectedSquare = square;
            highlightLegalMoves(square); // gold highlight on selected, green on legal moves
        }
        return;
    }
    // Second click — try to make the move
    const move = game.move({ from: selectedSquare, to: square, promotion: 'q' });
    if (move) {
        selectedSquare = null;
        sync3DWithEngine();
        saveToFirebase(); // broadcast to the other player
    }
}

Replicate It Yourself

  1. Create a Firebase project. Go to Firebase Console, create a project, add a web app, and enable Realtime Database (start in test mode for development). Copy the SDK config object.
  2. Load Three.js and chess.js via CDN. In your HTML, add script tags for three.min.js, OrbitControls.js, and chess.min.js before your app script. Reference: Three.js docs, chess.js GitHub.
  3. Build the board with BoxGeometry tiles. Create 64 THREE.BoxGeometry(0.96, 0.18, 0.96) meshes, position them in an 8×8 grid, and give each a userData.square = "e4" string for raycasting identification.
  4. Use LatheGeometry for piece shapes. Define the profile of each Staunton piece as an array of [radius, height] control points. Pass them to new THREE.LatheGeometry(points, 48) to get a rotationally symmetric mesh. Reference: Three.js LatheGeometry.
  5. Wire Firebase sync. On move, call firebase.database().ref('current_match').set({ fen: game.fen() }). In loadFromFirebase(), attach .on('value', snap => { game.load(snap.val().fen); rebuildPieces(); }). Reference: Firebase Realtime Database — Read and Write.
  6. Deploy to GitHub Pages (static files). The Firebase Spark (free) plan covers hobby use. Go to repo Settings → Pages → Source: Deploy from branch → main / (root). Reference: GitHub Pages docs.
