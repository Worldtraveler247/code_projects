Ansible Facts Trainer

Work the way you will on the exam: look the fact up with ansible servera -m setup, edit the playbook, and run it. The facts are a real capture from servera, a CentOS Stream 9 lab host, with identifying values replaced.

Control node terminal

  1. List the host's facts, as you would on the exam: ansible servera -m setup
  2. Too long to read? Page it with | less, or search it with | grep -i word.
  3. In a playbook, facts live in ansible_facts without the ansible_ prefix: ansible_hostname becomes ansible_facts['hostname'].
