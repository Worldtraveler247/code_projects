Dashboard — How It's Built

Live clock, real-time weather via Open-Meteo, and a background color switcher — no API key required.

Overview

The Dashboard is a browser-based productivity widget that shows a live digital clock with a time-of-day greeting, and pulls the current weather for the user's GPS location using the Open-Meteo API — a completely free weather API that requires no signup or API key. A background color button cycles through four dark gradient themes. The entire app is three files and no build step.

Tech Stack

HTML CSS JavaScript Open-Meteo API Geolocation API
  • HTML — semantic layout: clock display, greeting text, weather card, color-change button
  • CSS — dark gradient background, centered card layout, clock font styling
  • JavaScript — clock interval, geolocation request, Open-Meteo fetch, WMO weather code mapping
  • Open-Meteo API — free, no-key weather API that returns current conditions given latitude/longitude
  • Geolocation API — browser API that asks the user to share their location, returning lat/lon coordinates

How Each Part Works

script.js — clock and greeting

updateClock() creates a new Date object every second, formats hours/minutes/seconds with zero-padding, and updates the DOM. It also sets a greeting string based on the hour — morning, afternoon, or evening. setInterval(updateClock, 1000) starts the loop, and updateClock() is called immediately so the clock shows the right time before the first tick. 

function updateClock() {
    const now     = new Date();
    const hours   = String(now.getHours()).padStart(2, '0');   // "09"
    const minutes = String(now.getMinutes()).padStart(2, '0');
    const seconds = String(now.getSeconds()).padStart(2, '0');

    document.getElementById('clock').textContent = `${hours}:${minutes}:${seconds}`;

    // Greeting changes based on hour of day
    const greetingElement = document.getElementById('greeting');
    if (hours < 12)      greetingElement.textContent = "Good Morning!";
    else if (hours < 18) greetingElement.textContent = "Good Afternoon!";
    else                 greetingElement.textContent = "Good Evening!";
}

setInterval(updateClock, 1000);
updateClock();  // call immediately — don't wait 1s for first display

script.js — geolocation + Open-Meteo fetch

fetchWeather() first asks the browser for the user's GPS coordinates via navigator.geolocation.getCurrentPosition(). Inside the success callback, it builds an Open-Meteo URL with those coordinates and calls fetch(). The response JSON contains a current_weather object with temperature and a WMO weather code that maps to a human-readable description. 

async function fetchWeather() {
    if (!navigator.geolocation) {
        document.getElementById('weather-loading').textContent = "Geolocation not supported";
        return;
    }

    navigator.geolocation.getCurrentPosition(async (position) => {
        const { latitude, longitude } = position.coords;
        try {
            // Open-Meteo: free, no API key, no account needed
            const url = `https://api.open-meteo.com/v1/forecast`
                      + `?latitude=${latitude}&longitude=${longitude}`
                      + `¤t_weather=true`;
            const response = await fetch(url);
            const data     = await response.json();

            const weather = data.current_weather;
            document.getElementById('temp').textContent = Math.round(weather.temperature);
            document.getElementById('weather-desc').textContent =
                getWeatherDescription(weather.weathercode); // WMO code → text

            document.getElementById('weather-loading').classList.add('hidden');
            document.getElementById('weather-info').classList.remove('hidden');
        } catch (error) {
            document.getElementById('weather-loading').textContent = "Error loading weather";
        }
    }, (error) => {
        document.getElementById('weather-loading').textContent = "Location access denied";
    });
}

fetchWeather(); // call on page load

script.js — WMO weather code mapping

The Open-Meteo API returns a WMO (World Meteorological Organization) numeric code for current conditions. getWeatherDescription() maps those codes to plain-English strings. This avoids the need for a weather icon library while still giving useful descriptions. 

function getWeatherDescription(code) {
    const descriptions = {
        0:  "Clear sky",
        1: "Mainly clear", 2: "Partly cloudy", 3: "Overcast",
        45: "Fog",         48: "Depositing rime fog",
        51: "Light drizzle", 53: "Moderate drizzle", 55: "Dense drizzle",
        61: "Slight rain",   63: "Moderate rain",    65: "Heavy rain",
        71: "Slight snow",   73: "Moderate snow",    75: "Heavy snow",
        95: "Thunderstorm"
    };
    return descriptions[code] || "Variable conditions";
}

Replicate It Yourself

  1. Build the HTML structure. You need at minimum: a <span id="clock">, a <p id="greeting">, and a weather section with a loading state and a hidden info state that shows once the fetch resolves.
  2. Add the clock. In JS, call new Date() and format getHours(), getMinutes(), getSeconds() with String.padStart(2, '0'). Wrap this in a function and call it with setInterval(fn, 1000). Reference: MDN Date.
  3. Request location. Call navigator.geolocation.getCurrentPosition(successCallback, errorCallback). The success callback receives a position object with coords.latitude and coords.longitude. Reference: MDN Geolocation API.
  4. Call Open-Meteo. Inside the success callback, fetch(`https://api.open-meteo.com/v1/forecast?latitude=${lat}&longitude=${lon}¤t_weather=true`) and .then(r => r.json()). No API key needed. Reference: Open-Meteo API docs.
  5. Map WMO weather codes to text. Build a simple { code: "description" } object and look up data.current_weather.weathercode in it. Handle missing codes with a fallback string. Reference: WMO weather interpretation codes.
  6. Deploy to GitHub Pages. Push to main, go to repo Settings → Pages → Source: Deploy from branch → main / (root). Reference: GitHub Pages docs.
