Cloud Security Languages — How It's Built

A multi-page learning hub for Go, Python, and Bash — runnable code examples, primary-source references, no JS framework.

Overview

Cloud Security Languages is a static multi-page learning resource that teaches the three languages cloud security engineers use most: Go, Python, and Bash. Each language has its own deep-dive page with concept explanations, runnable code blocks, copy-to-clipboard buttons, a nav breadcrumb back to the hub, and references to official primary sources (go.dev, docs.python.org, GNU bash manual). All pages share a single CSS file and a small shared JS file. There is no framework, no build step, and no server.

Tech Stack

HTML CSS JavaScript
  • HTML — hub index with language cards, per-language content pages with sectioned lessons
  • CSS — shared cloud-langs.css with dark theme, code block styling, nav breadcrumb, badge chips
  • JavaScript — shared js/copy.js for copy-to-clipboard on code blocks; no other JS needed

js/ — shared copy-to-clipboard

A small shared JS file adds a "Copy" button to every <pre><code> block on the page. When clicked, it reads the code block's text content, writes it to the clipboard via navigator.clipboard.writeText(), and shows brief "Copied!" feedback. The button is inserted by JS so code still reads cleanly without it when JS is disabled. 

// Shared copy-to-clipboard (simplified from js/ shared file)
document.querySelectorAll('pre code').forEach(block => {
  const btn = document.createElement('button');
  btn.className = 'copy-btn';
  btn.textContent = 'Copy';

  btn.addEventListener('click', async () => {
    try {
      await navigator.clipboard.writeText(block.textContent);
      btn.textContent = 'Copied!';
      setTimeout(() => { btn.textContent = 'Copy'; }, 1500);
    } catch (err) {
      btn.textContent = 'Failed';
    }
  });

  // Insert the button as the first child of the pre element
  block.parentElement.insertBefore(btn, block);
});

Replicate It Yourself

  1. Create a hub index with sub-page links. Start with index.html listing your languages or topics as cards. Link each card to language/index.html using relative paths. Mark incomplete pages with a "coming soon" CSS class.
  2. Write per-language content pages. Each is a long HTML document with <section id="concept-name"> blocks. Use <pre><code> for all code samples. Add a table of contents with <a href="#concept-name"> links at the top.
  3. Link official docs for every claim. Every time you say "Go has X feature," link to the relevant section of go.dev, docs.python.org, or the GNU bash manual. This builds credibility and gives readers a path to go deeper. Reference: go.dev docs, Python docs, GNU Bash Manual.
  4. Add copy-to-clipboard with navigator.clipboard. Query all pre code elements, create a button per block, and call navigator.clipboard.writeText(block.textContent) on click. Show "Copied!" feedback with a setTimeout reset. Reference: MDN Clipboard.writeText.
  5. Share CSS across all pages via relative path. In each sub-page: <link rel="stylesheet" href="../css/shared.css">. This means one file change updates all pages' styling.
  6. Deploy to GitHub Pages. Push to main, go to repo Settings → Pages → Source: Deploy from branch → main / (root). Reference: GitHub Pages docs.
