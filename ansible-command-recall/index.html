Ansible Command Recall

Each card asks for one command, config line or file. Type it from memory, the way you would at the prompt. Answers are compared by meaning: option order, user versus ansible.builtin.user, and yes versus true do not matter; curly quotes, en dashes and capital letters do, because the shell cares. A missed card comes back three cards later. A card counts as known after three right answers in a row.
