Live Market Dashboard

Stock Monitor

Real-time buy alerts for VOO, SPY, QQQ, NVDA, AAPL, LLY, and BTC powered by Yahoo Finance. Configurable SMA and RSI thresholds, VIX regime badge, persistent watchlist, and optional Slack/ntfy webhook notifications — all in a single Python file deployed on Streamlit Cloud.

Data Source

Yahoo Finance via yfinance. 3-month OHLCV history per ticker, cached for 5 minutes to avoid rate-limiting.

Buy Signal Logic

Price >N% below the 20-day SMA or RSI(14) below the oversold threshold. Both thresholds are tunable via sidebar sliders.

VIX Regime

Calm <15 · Elevated 15–25 · Fear >25. The badge updates on every data refresh and drives contextual coloring across the dashboard.

Webhook Alerts

POST JSON payload to Slack or ntfy when a signal fires. URL is read from ALERT_WEBHOOK_URL in Streamlit secrets — never hardcoded.

Stack

Python 3.12 · Streamlit · yfinance · Pandas · Altair · requests. Deployed free on Streamlit Community Cloud.

Watchlist

Custom tickers persist across page reloads via a local JSON sidecar file. On Streamlit Cloud the default watchlist is used on each cold start.
