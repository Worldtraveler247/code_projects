HOW IT'S BUILT

Stock Monitor

A live Streamlit dashboard that fetches Yahoo Finance data, computes SMA and RSI, fires configurable buy alerts, and posts webhook notifications — all in a single Python file.

Overview

Stock Monitor is a Streamlit web app written in Python. It pulls live OHLCV data from Yahoo Finance via yfinance, computes two technical indicators (20-day simple moving average and 14-period Wilder RSI), and flags tickers that meet configurable buy-alert thresholds. The dashboard is organized into tabs for market sectors, an IPO watch list, an AI race tracker, and 2026–2027 revenue projections. Streamlit handles all the UI — widgets, layout, and re-renders — so there is no HTML, no JavaScript, and no separate frontend. The entire app is one file: app.py.

Tech Stack

Python 3.12+ Streamlit yfinance Pandas Altair
  • Python 3.12+ — the only runtime; type hints on every function make the data flow easier to follow and catch type errors before they reach the UI.
  • Streamlit — turns Python functions into interactive web components. Call st.metric(), st.dataframe(), or st.altair_chart() and Streamlit handles the DOM. Running streamlit run app.py is the entire deploy command locally.
  • yfinance — a thin wrapper around Yahoo Finance's unofficial API. yf.Ticker(symbol).history(period="3mo") returns a Pandas DataFrame of OHLCV rows with no API key required.
  • Pandas — used for all indicator math: rolling().mean() for SMA, diff() and ewm() for Wilder's RSI, and melt() to reshape the revenue projection table for charting.
  • Altair — a declarative charting library built on Vega-Lite. Used for the grouped horizontal bar chart in the revenue projections tab.

How Each Part Works

app.py — Data fetch with explicit per-ticker error handling

The core data loader is a cached function that iterates over the ticker watchlist. For each ticker it calls yf.Ticker(t).history(period="3mo"), then computes the 20-day SMA and RSI. Each ticker failure is caught and logged individually — stale or missing tickers surface in the sidebar warning rather than being silently swallowed.

@st.cache_data(ttl=300, show_spinner=False)
def load_market_data(tickers: tuple) -> list[dict]:
    rows: list[dict] = []
    failed: list[str] = []
    for t in tickers:
        try:
            hist = yf.Ticker(t).history(period="3mo")
            if hist.empty or len(hist) < SMA_WIN + RSI_WIN + 2:
                logging.warning("ticker %s: insufficient data (%d rows)", t, len(hist))
                failed.append(t)
                continue
            ...
        except Exception as exc:
            logging.error("ticker %s fetch failed: %s", t, exc)
            failed.append(t)
    return rows

app.py — Watchlist persistence with session_state + JSON sidecar

Streamlit re-runs the entire script on every interaction, but st.session_state persists across re-runs within the same browser session. A JSON sidecar file (watchlist.json) persists the watchlist across full page reloads. On startup the app reads the file into session state once; edits write back to disk immediately.

WATCHLIST_FILE = Path(__file__).parent / "watchlist.json"

def load_watchlist() -> list[str]:
    if WATCHLIST_FILE.exists():
        with WATCHLIST_FILE.open() as f:

    return list(DEFAULT_TICKERS)

def save_watchlist(tickers: list[str]) -> None:
    with WATCHLIST_FILE.open("w") as f:
        json.dump(tickers, f)

app.py — Wilder's RSI calculation

RSI is computed with exponential moving averages rather than simple averages, matching the Wilder smoothing method used by most trading platforms. clip(lower=0) isolates gains, clip(upper=0) isolates losses (negated), then ewm(alpha=1/period) applies the decay.

def calc_rsi(close: pd.Series, period: int = 14) -> float:
    """Wilder's smoothed RSI — returns the most-recent value."""
    d  = close.diff()
    ag = d.clip(lower=0).ewm(alpha=1 / period, adjust=False, min_periods=period).mean()
    al = (-d.clip(upper=0)).ewm(alpha=1 / period, adjust=False, min_periods=period).mean()
    rs = ag / al
    return float((100 - 100 / (1 + rs)).iloc[-1])

app.py — Alert history log + VIX regime badge

Every time a buy-signal fires, a timestamped entry is appended to st.session_state["alert_history"]. The list is rendered in a collapsible expander so you can scroll back through past alerts within the session. The VIX badge reads the live VIX value and applies a three-tier regime label: calm (<15), elevated (15–25), fear (>25).

if "alert_history" not in st.session_state:
    st.session_state["alert_history"] = []

def record_alerts(buy_rows: list[dict]) -> None:
    ts = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    for r in buy_rows:
        st.session_state["alert_history"].append(
            {"time": ts, "ticker": r["ticker"],
             "price": r["price"], "trigger": r["trigger"]}
        )

app.py — Webhook alerts (Slack / ntfy)

When a buy signal fires the app POSTs a JSON payload to a webhook URL read from st.secrets["ALERT_WEBHOOK_URL"] (or the ALERT_WEBHOOK_URL environment variable). If the secret is unset the POST is silently skipped — the app degrades gracefully rather than crashing. The webhook URL is never hardcoded because this repo is public.

def fire_webhook(buy_rows: list[dict]) -> None:
    """POST buy-signal payload to the configured webhook.

    Secret name: ALERT_WEBHOOK_URL
    Set in Streamlit Cloud: App Settings → Secrets → ALERT_WEBHOOK_URL = "https://..."
    Set locally: export ALERT_WEBHOOK_URL="https://..."
    """
    url = st.secrets.get("ALERT_WEBHOOK_URL") or os.environ.get("ALERT_WEBHOOK_URL")
    if not url:
        logging.debug("ALERT_WEBHOOK_URL not set — skipping webhook POST")
        return
    payload = {
        "text": "Stock Monitor — Buy Alerts",
        "alerts": [{"ticker": r["ticker"], "price": r["price"],
                    "trigger": r["trigger"]} for r in buy_rows],
    }
    try:
        resp = requests.post(url, json=payload, timeout=5)
        resp.raise_for_status()
    except requests.RequestException as exc:
        logging.error("webhook POST failed: %s", exc)

Security Notes

  • No hardcoded secrets. The webhook URL is read from st.secrets or an environment variable. Never commit it to Git — the repo is public.
  • Graceful degradation. If ALERT_WEBHOOK_URL is unset the POST is skipped and a debug log line is emitted. The dashboard continues to function normally.
  • Per-ticker error handling. Each yfinance fetch is wrapped individually. A single failed ticker logs a warning and is skipped — it does not crash the cache function or suppress data for the other tickers.
  • Streamlit secrets vs. env vars. On Streamlit Cloud use the built-in secrets manager (App Settings → Secrets). Locally export ALERT_WEBHOOK_URL=… or add it to stock-monitor/.streamlit/secrets.toml (git-ignored).

Replicate It Yourself

  1. Install dependencies: pip install streamlit yfinance pandas altair requests
  2. Fetch data with yfinance: hist = yf.Ticker("AAPL").history(period="3mo") — returns a Pandas DataFrame of OHLCV rows indexed by date.
  3. Compute the 20-day SMA: hist["Close"].rolling(20).mean().
  4. Implement RSI using Wilder's smoothing: compute daily deltas with diff(), separate gains/losses with clip(), apply ewm(alpha=1/14), then apply 100 - 100 / (1 + RS).
  5. Add a buy-signal boolean: price < sma * (1 - threshold) or rsi < 30.
  6. Persist the watchlist: write a load_watchlist() / save_watchlist() pair that reads/writes a JSON file; guard with if "watchlist" not in st.session_state to run only on first load.
  7. Add webhook: read URL from st.secrets.get("ALERT_WEBHOOK_URL"), skip if unset, POST with requests.post(url, json=payload, timeout=5).
  8. Deploy free on Streamlit Community Cloud: connect your GitHub repo, point at app.py, add secrets in App Settings.
