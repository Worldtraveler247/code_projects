Stock Monitor — How It's Built

A live Streamlit dashboard that fetches Yahoo Finance data, computes SMA and RSI, and surfaces buy alerts — all in a single Python file.

Overview

Stock Monitor is a Streamlit web app written in about 750 lines of Python. It pulls live OHLCV data from Yahoo Finance via yfinance, computes two technical indicators (20-day simple moving average and 14-period RSI), and flags tickers that meet configurable buy-alert thresholds. The dashboard is organized into tabs for market sectors, an IPO watch list, an AI race tracker, and 2026–2027 revenue projections. Streamlit handles all the UI — widgets, layout, and re-renders — so there is no HTML, no JavaScript, and no separate frontend. The entire app is one file: app.py.

Tech Stack

Python Streamlit yfinance Pandas Altair
  • Python 3.12+ — the only runtime; type hints on every function make the data flow easier to follow and catch type errors before they reach the UI.
  • Streamlit — turns Python functions into interactive web components. Call st.metric(), st.dataframe(), or st.altair_chart() and Streamlit handles the DOM. Running streamlit run app.py is the entire deploy command locally.
  • yfinance — a thin wrapper around Yahoo Finance's unofficial API. yf.Ticker(symbol).history(period="3mo") returns a Pandas DataFrame of OHLCV rows with no API key required.
  • Pandas — used for all the indicator math: rolling().mean() for SMA, diff() and ewm() for Wilder's RSI, and melt() to reshape the revenue projection table for charting.
  • Altair — a declarative charting library built on Vega-Lite. Used for the grouped horizontal bar chart in the revenue projections tab; st.altair_chart() renders it inside Streamlit.

How Each Part Works

app.py — Data fetch with yfinance + SMA/RSI

The core data loader is a cached function that iterates over the ticker watchlist. For each ticker it calls yf.Ticker(t).history(period="3mo") to get three months of daily closes, then computes the 20-day SMA with Pandas rolling().mean() and the RSI with a Wilder-smoothed exponential average. The @st.cache_data(ttl=300) decorator stores the result for 5 minutes so the app does not hammer the Yahoo Finance API on every UI interaction.

@st.cache_data(ttl=300, show_spinner=False)
def load_market_data(tickers: tuple) -> list[dict]:
    """Fetch OHLCV history for each ticker and compute SMA / RSI metrics."""
    rows = []
    for t in tickers:
        try:
            hist = yf.Ticker(t).history(period="3mo")
            if hist.empty or len(hist) < SMA_WIN + RSI_WIN + 2:
                continue
            c     = hist["Close"]
            price = float(c.iloc[-1])
            prev  = float(c.iloc[-2])
            sma   = float(c.rolling(SMA_WIN).mean().iloc[-1])
            rsi   = calc_rsi(c, RSI_WIN)
            rows.append({
                "ticker":  t,
                "name":    COMPANY.get(t, t),
                "price":   price,
                "day_chg": (price - prev) / prev * 100,
                "sma20":   sma,
                "vs_sma":  (price - sma) / sma * 100,
                "rsi":     rsi,
                "_hist":   hist,
            })
        except Exception:
            pass
    return rows

app.py — Price metric cards with st.metric()

After fetching data, the app renders one metric card per ticker using st.metric(). Streamlit lays out the cards in columns automatically when you call st.columns(n) and iterate over the result. The delta parameter makes Streamlit color the day-change value green or red automatically.

cols = st.columns(len(sorted_raw))
for col, r in zip(cols, sorted_raw):
    with col:
        st.metric(
            label=r["ticker"],
            value=f"${r['price']:,.2f}" if r["ticker"] != "^VIX" else f"{r['price']:.2f}",
            delta=f"{r['day_chg']:+.2f}%",
        )

app.py — Wilder's RSI calculation

RSI is computed with exponential moving averages rather than simple averages, matching the Wilder smoothing method used by most trading platforms. clip(lower=0) isolates gains, clip(upper=0) isolates losses (negated), then ewm(alpha=1/period) applies the decay. The final value is the classic 100 - 100 / (1 + RS) formula.

def calc_rsi(close: pd.Series, period: int = 14) -> float:
    """Wilder's smoothed RSI — returns the most-recent value."""
    d  = close.diff()
    ag = d.clip(lower=0).ewm(alpha=1 / period, adjust=False, min_periods=period).mean()
    al = (-d.clip(upper=0)).ewm(alpha=1 / period, adjust=False, min_periods=period).mean()
    rs = ag / al
    return float((100 - 100 / (1 + rs)).iloc[-1])

app.py — Buy alert logic

Alert thresholds are set by two sidebar sliders and evaluated in annotate_signals(). A ticker triggers a buy alert if its current price is more than N% below its 20-day SMA OR its RSI is below the oversold threshold. Both conditions are stored per-row so the UI can explain exactly which rule fired.

Replicate It Yourself

  1. Install dependencies: pip install streamlit yfinance pandas altair
  2. Fetch data with yfinance: hist = yf.Ticker("AAPL").history(period="3mo") — the result is a Pandas DataFrame of OHLCV rows indexed by date.
  3. Compute the 20-day SMA: hist["Close"].rolling(20).mean() — Pandas handles the windowed average; the first 19 rows will be NaN until enough data accumulates.
  4. Implement RSI using Wilder's smoothing: compute daily deltas with diff(), separate gains and losses with clip(), apply ewm(alpha=1/14) to each, then apply 100 - 100 / (1 + RS).
  5. Add a buy-signal boolean column: price < sma * (1 - threshold) or rsi < 30.
  6. Render metric cards: st.columns(n) + st.metric(label, value, delta) for each ticker. Add st.altair_chart() for the revenue bar chart.
  7. Deploy for free on Streamlit Community Cloud: connect your GitHub repo, point it at app.py, and it runs at a public URL within minutes.
