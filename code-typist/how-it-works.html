Code Typist — How It's Built

A typing tutor for Go, Python, and Bash — with a live on-screen keyboard and finger hints.

Overview

Code Typist is a browser-based typing tutor that trains you on real, idiomatic code snippets in Go, Python, and Bash — the three languages most useful for cloud security work. As you type, the on-screen keyboard lights up the next target key in cyan and neon line-art hand diagrams highlight which finger to use, so you build proper touch-typing habits while learning syntax at the same time. There is no backend, no build step, and no dependencies beyond the browser.

Tech Stack

HTML CSS JavaScript SVG
  • HTML — structures the keyboard grid, the snippet display area, the stats bar, and the SVG hand diagrams
  • CSS — dark neon theme, CSS Grid for the key layout, transition animations for key press feedback
  • JavaScript — all game logic: keydown event handling, cursor tracking, WPM/accuracy math, finger-hint mapping
  • SVG — the left and right hand diagrams are inline SVG; JS toggles .active on individual finger groups

How Each Part Works

snippets.js

Defines a single global object SNIPPETS with three keys — go, python, bash — each holding an array of snippet objects. Every snippet has a title and a code string. The file is loaded before app.js so the game engine can call SNIPPETS[lang] immediately. 

// Each entry is a { title, code } object.
// Tabs are replaced with 4-space indent so the browser
// doesn't intercept Tab keypresses mid-snippet.
const SNIPPETS = {
  go: [
    {
      title: "HTTP hello server",
      code: `package main

import (
    "fmt"
    "net/http"
)

func handler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, "Hello, %s!", r.URL.Path[1:])
}

func main() {
    http.HandleFunc("/", handler)
    http.ListenAndServe(":8080", nil)
}`,
    },
    // ... 9 more Go snippets, 10 Python, 10 Bash
  ],
};

app.js — keydown handler

The heart of the app. A single keydown listener on document compares e.key (the character produced) against state.snippet[state.pos] (the expected character). On a correct keystroke, the cursor advances; on wrong, an error is counted and the wrong character turns red. Backspace can correct one wrong character without advancing the cursor. 

function handleKey(e) {
  // Ignore pure modifier keys — they don't produce characters
  if (e.key === 'Shift' || e.key === 'Control' || e.key === 'Alt' || e.key === 'Meta') return;
  if (state.pos >= state.snippet.length) return;

  startTimer();                   // starts clock on first real keypress

  const expected = state.snippet[state.pos];
  let typed = e.key;
  if (typed === 'Enter') typed = '\n'; // normalize Enter → newline

  if (typed.length === 1) {       // single printable character
    if (typed === expected) {
      flashKey(e.code, true);     // green flash on the key element
      state.pos += 1;             // advance cursor
      state.wrongChar = false;
      if (state.pos >= state.snippet.length) { complete(); return; }
      renderSnippet();
      highlightTarget();          // light up the NEXT key on the keyboard
      updateStats();
    } else {
      flashKey(e.code, false);    // red flash
      state.errors += 1;
      state.wrongChar = true;
      renderSnippet();
      updateStats();
    }
  }
}

document.addEventListener('keydown', handleKey);

app.js — charToKey map and finger hints

At startup, the KEYBOARD layout array is walked to build charToKey — a map from every producible character to the key code and finger label that types it. When highlightTarget() is called, it looks up the next character in this map and adds the .target class to the matching key element and the .active class to the matching finger group in the SVG hand. 

// charToKey is built by walking the KEYBOARD layout once at startup.
// Each entry looks like: charToKey['A'] = { code: 'KeyA', finger: 'lp', needsShift: true }
const charToKey = {};
for (const row of KEYBOARD) {
  for (const key of row) {
    if (key.label && key.label.length === 1)
      charToKey[key.label] = { code: key.code, finger: key.finger, needsShift: false };
    if (key.shifted)
      charToKey[key.shifted] = { code: key.code, finger: key.finger, needsShift: true };
  }
}

function highlightTarget() {
  document.querySelectorAll('.key.target').forEach(k => k.classList.remove('target'));
  const ch = state.snippet[state.pos];
  const mapping = charToKey[ch];
  if (!mapping) return;

  // Light up the key on the on-screen keyboard
  (keyEls[mapping.code] || []).forEach(k => k.classList.add('target'));

  // If shift is needed, light the opposite-hand shift key
  if (mapping.needsShift) {
    const shiftCode = mapping.finger.startsWith('l') ? 'ShiftRight' : 'ShiftLeft';
    (keyEls[shiftCode] || []).forEach(k => k.classList.add('target'));
  }

  // Light the correct finger on the SVG hand diagram
  const hand = mapping.finger.startsWith('l') || mapping.finger === 'thumb'
    ? leftHand : rightHand;
  const fingerEl = hand.querySelector(`[data-finger="${mapping.finger}"]`);
  if (fingerEl) fingerEl.classList.add('active');
}

index.html — hand SVG structure

Each hand is an inline SVG with <g data-finger="..."> groups for each finger. JS selects these groups by the data-finger attribute and toggles the .active class. CSS then applies the neon highlight to the fingertip circle and stem path inside that group.

Replicate It Yourself

  1. Structure the page. Create an index.html with a <pre id="snippet"> for the text display, a hidden <input> to capture focus on mobile, and a <section id="keyboard"> that JS will populate with key divs. Reference: MDN pre element.
  2. Define snippets as a plain JS array. In snippets.js, create const SNIPPETS = { go: [...], python: [...], bash: [...] }. Each entry is { title: "...", code: "..." }. Use template literals for multiline code. Replace tab characters with 4 spaces so the browser doesn't swallow Tab keypresses.
  3. Build the keydown compare loop. In app.js, listen for document.addEventListener('keydown', handler). Compare e.key against the expected character at the current cursor position. Advance the cursor on correct, increment errors on wrong, allow Backspace to undo one mistake. Reference: MDN KeyboardEvent.key.
  4. Build the keyboard grid. Define a KEYBOARD array of rows; each key is { label, code, shifted, finger, width? }. Loop over it in JS and call document.createElement('div') for each key, storing references in a keyEls map keyed by event.code so you can highlight them instantly. Reference: MDN KeyboardEvent.code.
  5. Add finger hints. Walk the keyboard layout once to build a charToKey map. When the cursor advances, look up the next character and add .target to the key element and .active to the matching [data-finger] group in your SVG hand diagram.
  6. Deploy to GitHub Pages. Push to main, then go to repo Settings → Pages → Source: Deploy from branch → main / (root). Reference: GitHub Pages docs.
